<h1>COVID-19 Global Data Analysis</h1>
<p>This project presents a comprehensive exploratory data analysis (EDA) of the global COVID-19 pandemic using a dataset sourced from 
      <a href="https://www.kaggle.com/datasets/imdevskp/corona-virus-report" target="_blank">Kaggle</a>. 
      The analysis highlights trends, geographical distribution, and country-level insights related to confirmed cases, recoveries, and deaths from the virus.
    </p>
    <h2>Project Objectives</h2>
    <ul>
      <li>Clean and analyze real-world COVID-19 data.</li>
      <li>Identify and visualize countries with the highest and lowest number of cases.</li>
      <li>Explore patterns by WHO regions.</li>
      <li>Create compelling plots and charts for storytelling and insights.</li>
    </ul>
    <h2>Key Questions Answered</h2>
    <ul>
      <li>Which countries had the highest number of confirmed cases?</li>
      <li>Which regions were least affected?</li>
      <li>How were the cases distributed geographically across the globe?</li>
      <li>What is the comparison of recovered, active, and death counts by WHO regions?</li>
      <li>How did the pandemic evolve over time globally?</li>
    </ul>
    <h2>Visual Insights</h2>
    <ul>
      <li><span class="highlight">Global Scatter Map:</span> An interactive map displaying COVID-19 case distribution by latitude and longitude.</li>
      <li><span class="highlight">Top 10 Infected Countries:</span> A bar chart showing countries with the highest confirmed case counts (e.g., USA).</li>
      <li><span class="highlight">Least Affected Countries:</span> A plot showing countries with the lowest confirmed cases, including Western Sahara.</li>
      <li><span class="highlight">WHO Region Analysis:</span> A grouped bar chart comparing average recoveries, active cases, and deaths across WHO regions.</li>
    </ul>
    <h2>Tools & Technologies Used</h2>
    <ul>
      <li><strong>Python</strong>: Data wrangling and analysis</li>
      <li><strong>Pandas & NumPy</strong>: Data manipulation</li>
      <li><strong>Matplotlib & Seaborn</strong>: Static data visualizations</li>
      <li><strong>Plotly Express</strong>: Interactive map visualization</li>
      <li><strong>Jupyter Notebook</strong>: Interactive development environment</li>
    </ul>
